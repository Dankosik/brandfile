## What is the real format of the "render-safe brand kit," and what does "render-safe" mean in the code?

### Takeaway
The kit is a `brand/<id>/` directory of about 15 artifact types with three machine layers (`brand.spec.json` → `brand.json` → in-memory `brandContext`) and a large layer of prose written by the LLM. There is no formal schema. In the code, "render-safe" means a deterministic offline render (a legacy of the video pipeline), and not at all compliance with the brand.

### Inferences
- [inference] "Render-safe" solves the task "the file opens and renders the same way." It does not solve the task "the result matches the brand." In the final report these notions must not be mixed.
- [inference] There is in fact no single source of truth: colors live in the spec, `brand.json`, `design.md`, `GUIDELINES.md`, `prompts/system-prompt.md`, and `editorial/02`, with no consistency check.

### Gaps
- There is no real kit in the repository ([examples/README.md#L3-L6](https://github.com/GoldLegendW80/brand/blob/e2f2f4de9f2166c744a6079ce65fbf0c14e34db9/examples/README.md#L3-L6)), so its actual volume, file weight, and quality were not observed.

## How is /make-brand built: interview, extraction, or generation? What does the LLM decide, what is deterministic, and how are generic defaults avoided?

### Takeaway
GENERATE mode: an interview, a web audit of the category, the LLM generating directions, the user choosing in a browser, then deterministic generators and the LLM writing prose to fill in. IMPORT mode: crawling a portal plus the same. The methodology against generic results is strong, but its machine part works only as warnings, and the model gives itself the final score.

## How does /use-brand consume the kit on each surface? What templates and checks exist, what actually prevents drift, and at what point in the loop?

### Takeaway
There are generators and templates for all seven surfaces. There is one real protection against drift: a theme from CSS variables at the moment of generation. Everything after the render (contrast, fonts, colors, bans, voice) exists only as an instruction for the LLM. The skill does not enter the product's code or CI at all.

### Inferences
- [inference] For your goal 2 ("make agents follow the brand book"), the project gives strong starting context and zero enforcement. An agent writing a React component in an existing repository will get only `tokens.css`; nothing will stop it from typing a hex by hand.
- [inference] The `/use-brand` flow is designed for generating new standalone files. There is no scenario of "build the brand into existing code." ## What do Anthropic's brand-guidelines and theme-factory actually contain, and what does GoldLegendW80/brand add on top of them?

### Takeaway
Anthropic's baseline is reference cards: colors, fonts, and a short order of application, without scripts, checks, or a brand-creation process. GoldLegend adds a process, assets, voice, and generators, but adds no enforcement at the usage stage: in both cases it rests on the model itself.

### Cited Findings
- [code] `brand-guidelines` consists of `SKILL.md` (73 lines) and `LICENSE.txt` (Apache 2.0); there are no scripts (`rg --files`). The content concerns only Anthropic's brand: 4 main and 3 accent colors — [SKILL.md#L17-L30](https://github.com/anthropics/skills/blob/ca45fc496a3436251f191354091d557da31c15b5/skills/brand-guidelines/SKILL.md#L17-L30); Poppins and Lora with fallbacks Arial and Georgia — [L32-L36](https://github.com/anthropics/skills/blob/ca45fc496a3436251f191354091d557da31c15b5/skills/brand-guidelines/SKILL.md#L32-L36).
- [code] Automatic font application, accent rotation, and application through `python-pptx` are described as features ([L38-L73](https://github.com/anthropics/skills/blob/ca45fc496a3436251f191354091d557da31c15b5/skills/brand-guidelines/SKILL.md#L38-L73)), but there is no code in the directory. [inference] This is an instruction to the model, not a feature.
- [code] `theme-factory`: `SKILL.md` (59 lines), 10 theme files of 19 lines each, `theme-showcase.pdf`, a license; no scripts. The order: show the PDF, ask, wait for a choice, apply — [SKILL.md#L19-L26](https://github.com/anthropics/skills/blob/ca45fc496a3436251f191354091d557da31c15b5/skills/theme-factory/SKILL.md#L19-L26). A custom theme is created from one paragraph with a preview for approval ([L58-L59](https://github.com/anthropics/skills/blob/ca45fc496a3436251f191354091d557da31c15b5/skills/theme-factory/SKILL.md#L58-L59)).
- [code] Each theme: 4 colors, 2 fonts from DejaVu/FreeSans/FreeSerif, a purpose. For example, [tech-innovation.md#L5-L19](https://github.com/anthropics/skills/blob/ca45fc496a3436251f191354091d557da31c15b5/skills/theme-factory/themes/tech-innovation.md#L5-L19) (electric blue, neon cyan on dark), [midnight-galaxy.md#L5-L19](https://github.com/anthropics/skills/blob/ca45fc496a3436251f191354091d557da31c15b5/skills/theme-factory/themes/midnight-galaxy.md#L5-L19) (purple and lavender). `#264653` in [sunset-boulevard.md#L10](https://github.com/anthropics/skills/blob/ca45fc496a3436251f191354091d557da31c15b5/skills/theme-factory/themes/sunset-boulevard.md#L10) is labeled deep purple, although [inference] by its values it is a dark blue-green.

### Inferences
- [inference] The baseline's minimum bar is very low, and exceeding it in completeness is easy. The substantive question is a different one: whose effectiveness is higher at the same load on context and attention.
- [inference] The baseline wins in one respect: cheap application to any existing document. Your skills can keep this property by putting the main content into a compact bundle with pinpoint links to the details.

## What to avoid
1. **Calling a gate something that only the model itself carries out.** A conformance lint in prose does not replace an executable check. You need a script with an exit code and wiring through a hook, CI, or pre-commit.
2. **Warn-only passed off as hard fail:** the documents require regeneration on a violation, while the code carries on ([build-directions.mjs#L16](https://github.com/GoldLegendW80/brand/blob/e2f2f4de9f2166c744a6079ce65fbf0c14e34db9/skills/make-brand/scripts/build-directions.mjs#L16)).
3. **Several sources of truth without syncing** and a regeneration that erases manual work ([guidelines.mjs#L207](https://github.com/GoldLegendW80/brand/blob/e2f2f4de9f2166c744a6079ce65fbf0c14e34db9/skills/make-brand/scripts/guidelines.mjs#L207), [brand-kit.mjs#L180](https://github.com/GoldLegendW80/brand/blob/e2f2f4de9f2166c744a6079ce65fbf0c14e34db9/skills/make-brand/scripts/brand-kit.mjs#L180)). You need a split into generated and authored blocks and a diff on version change.
4. **Templates with made-up data and with devices that its own rules forbid** ([landing#L133-L160](https://github.com/GoldLegendW80/brand/blob/e2f2f4de9f2166c744a6079ce65fbf0c14e34db9/skills/use-brand/assets/web/landing.tmpl.html#L133-L160)). A placeholder should break the check, not look like finished content.
5. **Recoloring one layout instead of a system**, and losing the `layout/markLane` decisions after a direction is chosen.
6. **Self-assessment as the only evidence.** A rubric without an external judge and a control group measures nothing.
7. **Specifications that are filled in and not consumed:** `typeScale`, `clearSpace`, `neverPair`, `logoConstruction`, `overrides`, `deployRule`. Each field must have a consumer or a check.
8. **Latin-only and English-only checks**, if Russian and Cyrillic logos are needed ([vendor-fonts.mjs#L16](https://github.com/GoldLegendW80/brand/blob/e2f2f4de9f2166c744a6079ce65fbf0c14e34db9/skills/make-brand/scripts/vendor-fonts.mjs#L16)).
9. **A hard ban that conflicts with a working brand**, without a working exceptions mechanism.
10. **Compatibility claims without verification:** DTCG and `/make-video` diverge from the code. A contract with an external tool should be pinned by a test.
11. **Radii and spacing in tokens that are the same for everyone** ([tokens.mjs#L66-L75](https://github.com/GoldLegendW80/brand/blob/e2f2f4de9f2166c744a6079ce65fbf0c14e34db9/skills/use-brand/scripts/tokens.mjs#L66-L75)): made-up values look like brand decisions.
12. **A built-in dependence on one vertical:** video documents as a mandatory part of the core bloat the context for a team without video.
